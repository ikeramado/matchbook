# Roadmap

The slices of matchbook, in order. The first is a walking skeleton: the thinnest
version that runs end to end. Each slice lists the criteria from [CRITERIA.md](CRITERIA.md)
it covers, and every criterion belongs to one slice. A slice moves from Later to Next to
Now to Done; it can only be Done when each of its criteria has a test.

Format:

    ### S1. Walking skeleton
    Criteria: C1, C2
